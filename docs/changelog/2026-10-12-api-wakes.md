# 2026-10-12: page visits no longer wake the API, and it starts without torch (fixes #4)

Decision: `docs/decisions/deployment.md` ("What wakes the API, and the cold start"),
`docs/decisions/embeddings.md` (runtime), `docs/decisions/market-publication.md`.
Review page: `docs/local/api-wakes-review.html`.

## The problem

From 5 to 12 Oct a replica of `jobradar-backend` ran 5,181 of 11,519 minutes,
over 517 wakes. 477 of them began with `GET /market/look`: a server rebuild
of `/`, `/about` or `/product`. Every public page and the API fetch expired
after 5 minutes, so any visit or crawler after a quiet spell woke the API.
With `minReplicas: 0` every running second is billed at the active rate.

A cold start pulled a 588 MB image (10.4 s median) and loaded torch for
MiniLM.

## The fix

- Frontend: every public page and share image, and the sitemap, `revalidate`
  once a day; the fetch in `lib/landing/look-server.ts` too. The weekly
  publication's `/api/revalidate` stays the way a new week shows, and now
  also drops `/sitemap.xml`.
- Frontend: the market pages and the years page no longer set
  `dynamicParams = false`. With it, a local `next start` answered 404 for
  `/market/ai` and the years page after `/api/revalidate` (also with the
  code from #1). Unknown names are still a 404 from `notFound()`, with no API call.
- Backend: MiniLM runs on ONNX Runtime from the model's own ONNX export
  (`src/Agent/utils/embedder.py`), same vectors to 2.7e-7. torch,
  sentence-transformers, pandas, anthropic, xai-sdk, ipython and pgvector
  left `requirements.txt`; `requests` is now listed (it came in through xai-sdk).
  The Dockerfile bakes the two files the embedder names.

## Measured

Image 587 MB to 224 MB. Analysis stack load in the container 8.5 s to 1.3 s;
container start to stack loaded 10 to 14 s to 3.3 s; memory with the stack
loaded 490 to 251 MiB (local, amd64 under emulation). A local production
build: visits to the public pages made no API call; after `/api/revalidate`
the next visits refetched and every page answered 200.

## Tests

Backend `test_embedder.py` (new: the analysis stack loads without torch; the
cosines match the recorded sentence-transformers ones). Frontend
`page-wakes.test.ts` (new: every route's `revalidate` and the fetch are a day
or more), `revalidate.test.ts` (the sitemap is dropped; the revalidated pages
keep dynamic params). Each failed once with its fix disabled. Backend 689
passed on the local test DB, 642 passed and 19 skipped with `DATABASE_URL=""`,
637 passed inside the new image; frontend `tsc`, vitest and `next build` pass.
