  `https://seeglassbox.com` (`frontend/src/lib/site.ts`, tested). Used by the
  metadata base (`app/layout.tsx`), the sitemap, robots and the landing page's
  JSON-LD. The old `jobradar-frontend-pearl.vercel.app` is gone from the code.
- `frontend/.env.example` lists the variable.
- `backend/main.py`: the ALLOWED_ORIGINS example now names the new domain, without
  the trailing slash the old example had (a browser's Origin never has one).

  there), so no `AUTH_URL` is needed. The Google OAuth client still needs the new
  redirect URI.
