# The skill vocabulary matching reads. One skill per line:
#
#   key | Display name | category | aliases | related
#
# aliases  Comma-separated surface forms, matched as whole words, ignoring case.
#          Hyphens and slashes separate words, so "react-native" and "react native"
#          are one alias. A skill *name* resolves with its trailing qualifier
#          dropped, so EMSI's "Python (Programming Language)" and SkillNer output
#          land on the same keys as a CV's "python".
#            ^Word  only with this exact capitalisation ("React", not "react quickly")
#            ~Word  exact capitalisation AND inside a list ("Python, Go and Rust") —
#                   for names that are also ordinary words: Go, R, C, Spring, Express
# related  key=credit: knowing THIS skill earns partial credit toward THAT one.
#          Directional on purpose — Next.js implies React more than React implies Next.js.
#
# Only concrete technologies and domains belong here. Soft skills and generic CS
# vocabulary ("algorithms", "problem solving") are left out: nearly every posting
# asks for them and almost no CV lists them, so they would lower every score
# equally and separate nothing.
